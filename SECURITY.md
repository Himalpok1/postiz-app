# Security

If you find a security problem in Castrapid, please report it privately through [GitHub Security Advisories](https://github.com/Himalpok1/postiz-app/security/advisories/new). Do not open a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it. We will confirm receipt and tell you what happens next.

Only test against your own account and data. Do not access other people's data or disrupt the service.
