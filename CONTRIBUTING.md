# Contributing

Thanks for helping with Castrapid.

1. Open an issue first so we can agree on the change.
2. Create a branch from `main`.
3. Follow the rules in `CLAUDE.md`. They cover the backend layers, frontend conventions, database migrations and how to treat Temporal workflows.
4. Run lint from the repository root with pnpm, and test your change in the app.
5. Open a pull request using the template, including real numbered QA steps.

By contributing, you agree that your work is released under the project's license, AGPL-3.0.
